# Crastio — downloads and feedback

**Crastio** is a planner for Mac and Windows that shows every deadline as a ribbon of the time you
have left: tasks, a daily plan, courses, and projects you can share. It works offline and without an
account.

- **Website and download:** https://alighemires.github.io/crastio-releases/
- **Latest version:** see [Releases](https://github.com/AliGhemires/crastio-releases/releases/latest)
  (installers, checksums, and the signed update files the app uses to update itself)

Crastio is in **beta**. This repository holds the installers and the website; the source code is not
public.

## Give feedback or report a bug

[Open a ticket](https://github.com/AliGhemires/crastio-releases/issues/new/choose). Say which version
you use (Settings › About), Mac or Windows, and what happened. Tickets are public: remove anything
private from screenshots.
